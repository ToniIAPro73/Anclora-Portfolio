# Feature v1 — conversion-analytics-and-attribution-layer

Objetivo: instrumentar analítica de conversión y atribución para demostrar impacto comercial con datos trazables.

Alcance:

- Taxonomía de eventos críticos.
- Captura de UTMs y contexto de sesión.
- Ingestión backend validada con deduplicación.
- Métricas mínimas para lectura operativa.

Entregables:

- Cambios de frontend/backend trazables.
- Evidencia de tests + build + lighthouse.
- Gate final con decisión GO/NO-GO.
